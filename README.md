# Compat Recipe Master
Alternative recipe adding mod for Minecraft.   
Mod name is temporarily. It will be changed if I have a more great idea.

# What does do this mod?
Add various alternative recipes. This was originally a data pack intended for personal use only, which was turned into a mod. If you are curious about which recipes are added, please download and install it yourself.   
The single Java class file in this mod actually does nothing other than print a log message once indicating whether the mod was installed correctly. This is because most of this mod's contents are simply the data pack moved into a JAR file. If you are suspicious of the file, I strongly recommend that you scan it with at least one reliable professional scanning program before installing it in the game.

I have a plan to support recipes from more mods in the future.
